Light the Deal is a web app that support the electrition maintanace company to handle the premises and to support creating the offer for the premises.
It will be possible for the user to creat it's own material list or list with assitances which he offers as well to modify and delete them. It will be possible to create offer on a base of selected materials and assistance for the current premise. Later, when the offer is confirmed it will turn into order. It will be possible to modify the rows of the deal.
There is dedicated part for dayly tasks
